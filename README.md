# SupportFlow

SupportFlow는 고객 문의를 접수하고, 지원팀이 처리 우선순위를 판단하며, AI가 운영 맥락을 정리해주는 고객지원 운영 대시보드입니다.

고객은 문의를 남기고 답변을 확인합니다. 상담원은 배정된 문의를 처리하고 고객 답변과 내부 메모를 구분해 남깁니다. 관리자는 전체 문의 흐름, 담당자 배정, 응답 위험, AI 검토가 필요한 항목을 한 화면에서 확인합니다.

배포: https://supportflow-gules.vercel.app/

## 제품 개요

SupportFlow는 단순 문의 게시판이 아니라 실제 지원팀의 업무 흐름을 기준으로 구성된 운영 SaaS입니다.

- 문의 접수부터 답변 완료까지의 상태를 관리합니다.
- 고객, 상담원, 관리자 역할에 따라 볼 수 있는 정보가 다릅니다.
- 고객 공개 답변과 내부 메모를 분리합니다.
- 담당자, 우선순위, 상태, 카테고리, SLA 위험을 한 목록에서 확인합니다.
- AI가 문의 요약, 감정, 긴급도, 답변 초안을 제안합니다.
- AI가 만든 내용은 바로 고객에게 발송되지 않고 사람이 검토합니다.
- 위험하거나 신뢰도가 낮은 AI 판단은 운영자가 먼저 확인할 수 있게 표시합니다.

## 해결하려는 문제

고객지원팀은 문의가 많아질수록 단순히 답변 속도만 관리해서는 운영 품질을 유지하기 어렵습니다.

SupportFlow는 다음 문제를 줄이는 데 초점을 둡니다.

- 지금 먼저 봐야 하는 문의를 빠르게 찾기 어렵습니다.
- 환불, 결제, 보안, 부정 감정 같은 위험 신호를 놓치기 쉽습니다.
- 고객에게 보여도 되는 답변과 내부 공유용 메모가 섞이면 운영 사고가 날 수 있습니다.
- 상담원과 관리자의 권한과 책임 범위가 분리되어야 합니다.
- AI가 도움을 주더라도 최종 판단은 사람이 해야 합니다.

## 사용자 역할

| 역할 | 목적 | 주요 작업 |
| --- | --- | --- |
| 고객 | 문의를 남기고 답변을 확인 | 문의 등록, 내 문의 조회, 공개 답변 확인 |
| 상담원 | 배정된 문의를 처리 | 상태 변경, 고객 답변, 내부 메모, AI 분석 확인 |
| 관리자 | 전체 지원 운영을 관리 | 전체 문의 조회, 담당자 배정, 우선순위 조정, 운영 지표 확인 |

고객에게는 AI 분석, 내부 메모, 활동 로그, 담당자 운영 정보가 노출되지 않습니다.

## 주요 화면

### 공개 홈

제품의 핵심 흐름을 실제 화면 캡처 중심으로 보여주는 랜딩 페이지입니다. 문의 목록, AI 보조 패널, 운영 리포트 화면을 통해 SupportFlow가 어떤 제품인지 빠르게 파악할 수 있습니다.

### 문의함

지원팀이 가장 자주 보는 화면입니다. 문의 상태, 우선순위, SLA, 담당자, 태그, AI 신호, 업데이트 시간을 한 목록에서 확인합니다. 검색과 필터를 통해 답변 대기, 부정 감정, 긴급 문의를 빠르게 찾을 수 있습니다.

### 문의 상세

문의 내용, 공개 답변, 내부 메모, 상태 변경, 담당자 배정, 활동 흐름을 확인합니다. 상담원과 관리자는 오른쪽 AI 어시스턴트에서 문의 요약과 답변 초안을 참고할 수 있습니다.

### AI 검토

AI가 낮은 신뢰도나 위험 신호를 감지한 문의를 모아 보여줍니다. 운영자는 이 화면에서 놓치기 쉬운 긴급 문의나 부정 감정 문의를 먼저 확인할 수 있습니다.

### 운영 대시보드와 리포트

답변 대기 문의, 처리 상태, 담당자 부하, 카테고리 분포, 응답 위험 추이를 확인합니다. 지원팀의 병목과 운영 품질을 한눈에 점검하기 위한 화면입니다.

## AI가 돕는 방식

SupportFlow의 AI는 상담원을 대체하지 않습니다. 문의를 더 빨리 이해하고 우선순위를 판단할 수 있도록 돕는 보조 역할입니다.

AI는 다음 정보를 제안합니다.

- 문의 요약
- 카테고리
- 감정
- 긴급도
- 고객 의도
- 추천 우선순위
- 추천 상태
- 답변 초안
- 검토 필요 여부

답변 초안은 자동 발송되지 않습니다. 상담원이 직접 확인한 뒤 답변 작성란에 불러와 수정하고 제출합니다.

## 데모에서 볼 수 있는 흐름

1. 고객 계정으로 문의를 등록합니다.
2. 관리자 또는 상담원 계정으로 문의함에서 새 문의를 확인합니다.
3. AI가 분류한 감정, 긴급도, 검토 필요 신호를 목록에서 확인합니다.
4. 문의 상세에서 AI 요약과 답변 초안을 확인합니다.
5. 필요한 경우 답변 초안을 고객 답변 작성에 활용합니다.
6. 대시보드와 리포트에서 지원팀 운영 현황을 확인합니다.
